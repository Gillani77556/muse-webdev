# COMMANDS

| Command | Skill | What it does |
|---|---|---|
| `/webdev auto <topic>` | webdev-plan, webdev-brief, webdev-architecture | Build a complete website from just a topic — AUTO MODE (default, no questions first) |
| `/webdev build <brief>` | webdev-plan, webdev-brief, webdev-architecture | New website from scratch — same as `auto`, builds immediately with defaults |
| `/webdev audit <url>` | webdev-audit | Full site audit, score, fix list |
| `/webdev redesign <url>` | webdev-design, webdev-layout, webdev-design-polish | Make an old site beautiful |
| `/webdev fix <url>` | webdev-fix | Find the fault, fix it, live-check it |
| `/webdev page <url>` | webdev-page | Deep check of one page |
| `/webdev speed <url>` | webdev-performance | Speed and Core Web Vitals |
| `/webdev launch <url>` | webdev-deploy, webdev-client-ready | Deploy-ready final check |
| `/webdev plan <brief>` | webdev-plan | Build plan |
| `/webdev design <url>` | webdev-design | Design system review |
| `/webdev responsive <url>` | webdev-responsive | Mobile/tablet/desktop |
| `/webdev forms <url>` | webdev-forms | Forms end-to-end test |
| `/webdev security <url>` | webdev-security | HTTPS, headers, safe forms |
| `/webdev drift baseline <url>` | webdev-drift | Save a baseline |
| `/webdev drift compare <url>` | webdev-drift | Compare with the baseline |
| `/webdev senior-review <url>` | webdev-senior-review | Senior final review |
| `/webdev client-ready <url>` | webdev-client-ready | Client gate |

Plain English works too: write `use the webdev skill to ...` and the hub will understand.

**Every build ships the PREMIUM BUILD STANDARD (v0.2.0):** design-system
tokens, large photographic hero, real photos on every card (each URL verified
HTTP 200), a working interactive planner/calculator, full section
architecture (hero, trust bar, services, how-it-works, why-choose-us, places,
planner, FAQ, final CTA, footer), subtle animations, mobile-first responsive.
A plain site fails the senior-review gate.
