# USAGE — Muse AI mein ye skill kaise use karein

> Aap bas "website banao" bolo, peeche agents kaam karenge — design, build,
> check, polish — aap baat karte raho.

## Pehle: install (ek dafa)
```bash
git clone https://github.com/Gillani77556/muse-webdev.git
cd muse-webdev
bash install.sh
```
Phir Muse kholo aur neeche wali lines mein se ek likho.

## MAIN USE CASE — Scratch se nayi website (pehle)
User sirf apna program/brief deta hai, skill peeche se plan, design, build
aur check karti hai. Jo missing ho, skill khud poochhti hai.

### Misal 1 — Home cleaning business
```
webdev skill use karke meri home cleaning business ke liye scratch se
website banao. Business: ghar ki safai, Karachi. Services: deep cleaning,
sofa cleaning, kitchen cleaning. Phone/WhatsApp: [apna number likho].
Color: neela aur safed, saaf aur premium look chahiye.
```

### Misal 2 — Dukaan (shop)
```
webdev skill use karke meri kapron ki dukaan ke liye scratch se website
banao. Dukaan: [dukaan ka naam], Lahore. Products: mardana aur zanana
kapre. Prices list baad mein dunga. WhatsApp order button chahiye.
```

### Misal 3 — Service (plumber / electrician / salon)
```
webdev skill use karke meri plumbing service ke liye scratch se website
banao. Service: ghar ki plumbing, 24 hours. Area: Islamabad.
Phone: [apna number likho]. Customer ko foran call ya WhatsApp karna ho.
```

Skill peeche ye karegi: Step 1 brief lo (jo missing ho poochho), Step 2 plan,
Step 3 design system, Step 4 build, Step 5 live check + senior review +
client-ready gate. Aapko har waqt jawab nahi dena parta.

## Baaki commands (copy-paste)
1. Audit: `/webdev audit https://[aapki-site].com`
2. Redesign: `/webdev redesign https://[aapki-site].com` — purani site
   beautiful banao, content waisa hi rakho jab tak main na kahun.
3. Fix: `/webdev fix https://[aapki-site].com` — kharabi dhoondho aur fix karo.
4. Ek page: `/webdev page https://[aapki-site].com/services`
5. Speed: `/webdev speed https://[aapki-site].com`
6. Launch: `/webdev launch https://[aapki-site].com` — client ko bhejne se pehle final check.
7. Senior review: `/webdev senior-review https://[aapki-site].com`
8. Roman Urdu mein: `webdev skill use karke meri site ka audit karo: https://[aapki-site].com`
9. Roman Urdu mein: `webdev skill use karke meri site ko mobile par check karo, kuch kata hua to nahi`
10. Roman Urdu mein: `webdev skill use karke meri site ki speed aur forms test karo`

## Rules
- Business ki asal maloomat (naam, number, price, review) sirf aap denge.
  Skill guess nahi karegi — missing cheez `[TO CONFIRM]` likhegi.
- Backup pehle, live change aapki haan ke baad.
- Har kaam ke baad live check + screenshot proof.
